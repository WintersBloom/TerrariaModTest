# 原版减益（Debuff）完整清单

- 数据来源：`tModLoader.dll` 反编译的 `BuffID.cs` 与 `Main.cs`，以及 `zh_Hans.Game.json` 本地化
- `BuffID.Count = 355`（0–354 是原版，355 起是 mod）
- `Main.debuff` 里标了 **60** 项
- 其中 **14** 项其实是增益（原版把它们归进了这张表）
- 真正是减益的：官方表里 **46** 项 + 官方漏标 **5** 项 = **51** 项

> `Main.debuff` 的注释说「所有原版减益都在这里设为 true」，但实际它还塞进了
> 水蜡烛、心灯、旗帜这类**区域增益**，所以不能直接拿它当减益列表用。
